# Keep package outputs distinct

Select this domain for semiconductor-package architecture and explicitly
supported package thermal studies. RTL, PCB fabrication, RF networks and
general structural analysis own different outputs; a shared word such as
substrate or thermal does not make their workflows interchangeable.

Preserve scoped work on an existing model. Completion requires current native
evidence and independent review for the chosen numerical work, not unrelated
electrical, assembly or qualification stages.

If execution fails or original bounds are missed, retain that result and seek
an authorized in-scope correction. Do not change conductivity, cooling
conditions, power or tolerances merely to report success. Unsupported physics
and missing material data remain explicit limitations.

A completed model study does not approve a production package, authorize
commercial tool access or establish measured physical performance.
