# Match the PCB request to its evidence

Choose this domain for schematic/board engineering, native KiCad checks,
schematic-board consistency and fabrication file preparation. RF network
calculation, chip physical design and package engineering own different
outputs and should not be routed here simply because they mention copper.

Preserve verification-only work and optional full design development. Require
only the selected current evidence plus independent review. A truthful report
of unsupported input is not a completed native calculation; no temporary
placeholder or fabricated output may stand in for it.

When requirements fail, retain the result and request an in-scope correction or
state the unresolved issue. Do not increase tolerances, suppress native rules
or require unrelated stages to conceal failure. Successful file-level review
does not authorize manufacturing, purchasing or physical operation.
