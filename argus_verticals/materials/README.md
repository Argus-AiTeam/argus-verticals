# materials

**Purpose:** materials science and materials processing across atomistic, microstructure, continuum, CAD/CAE, and experimental scales.

Proportional workflow `scope → grounding → model → execute → validate → report` with independent review and research target levels `exploratory / publishable / doctoral`. The smallest complete vertical; use it as the template for a new one.

- `stages.py`: contract, checklists, completion checks.
- `evidence.py`: structural evidence index for execution, validation and reports.
- `skills/manager/`, `skills/planner/`, `skills/engineer/`, `skills/reviewer/`.

Extras: none. Tests: `tests/skills/test_materials_vertical.py`.
