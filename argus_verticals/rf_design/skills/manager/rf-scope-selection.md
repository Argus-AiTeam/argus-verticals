# Choose the requested result, not a larger project

Use this domain for RF network interpretation, S-parameter studies, reference
impedance/port handling, transmission-line reasoning and matching-network
calculations. For a supplied two-port file and a small set of gain/passivity
questions, choose analysis only. A new model or requirements discussion can
use its own scope without inventing simulation results.

Preserve requested bands, ports, references, bias conditions and numerical
acceptance. The optional full workflow is available but does not mandate
calibration, layout or every network operation. Independent review is needed
for each selected scope, not only for a separate report stage.

Distinguish analog time-domain circuit work from RF network analysis.
RTL verification belongs to the digital specialty; PCB/package implementation
belongs to its own domain. A need for antenna patterns, field distributions,
nonlinear device behavior or VNA calibration exceeds this first adapter.
Explain the missing method rather than selecting an unrelated check and
calling the original task complete.

Do not authorize hardware transmission or instrument operation through a
simulation task. A coherent, finite network study should end after its
requested comparisons and review, without expanding into an open-ended
radio design campaign.
